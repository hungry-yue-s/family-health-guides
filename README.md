# 体检结果解读与随访建议

用于发布两份体检报告解读的静态站点，不依赖构建框架。

## 页面

- `index.html`：阅读入口。
- `father.html`：父亲体检结果分析与随访建议。
- `mother.html`：母亲体检结果分析与随访建议。

## 部署

GitHub Pages 发布源为 `main` 分支根目录。`.nojekyll` 禁用 Jekyll 处理；后续推送至 `main` 后自动更新站点。

原始体检 PDF、录音转写、分析笔记和工作日志均在仓库外保存。

## 访问说明

本网站按所有者要求公开完整网页，无需密码。任何获得链接的人均可阅读页面内容。

页面的 `noindex` 元数据仅用于提示搜索引擎，不构成访问控制。
